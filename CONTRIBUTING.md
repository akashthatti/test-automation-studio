# Contributing to Test Automation Studio

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. **Fork the repository**
   ```bash
   git clone https://github.com/your-username/test-automation-studio.git
   ```

2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start development**
   ```bash
   npm run dev
   ```

## Code Style

- Use ES6+ syntax
- Follow React best practices
- Use meaningful variable names
- Add comments for complex logic
- Keep functions small and focused

## Commit Guidelines

- Use descriptive commit messages
- Start with emoji: `✨ Feature`, `🐛 Fix`, `📝 Docs`, `♻️ Refactor`, `🎨 Style`
- Example: `✨ Add cloud execution support`

## Pull Request Process

1. Update documentation if needed
2. Test your changes thoroughly
3. Ensure no console errors or warnings
4. Create a clear PR description
5. Link related issues
6. Wait for review and feedback

## Testing

- Test on Windows, Mac, and Linux if possible
- Test with different browsers
- Verify dark/light mode
- Check responsive design

## Reporting Bugs

**Before submitting:**
- Search existing issues
- Check if it's a known issue
- Try the latest version

**When submitting:**
- Provide clear description
- Steps to reproduce
- Expected vs actual behavior
- Screenshot or video if helpful
- System information

## Feature Requests

- Check the roadmap first
- Explain the use case
- Provide examples
- Consider alternatives
